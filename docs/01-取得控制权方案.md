# 第一步：取得 Sphero BOLT 的控制权

> 目标：在电脑上用 Python 通过蓝牙（BLE）连接 BOLT，并能让它亮灯、转向、滚动、读传感器。
> 这是后续所有开发（遥控、自动巡航、游戏等）的基础。

---

## 1. 可选的控制路线

| 路线 | 工具 | 优点 | 缺点 | 用途 |
| --- | --- | --- | --- | --- |
| A. 官方 App | Sphero Edu（iOS / Android / Windows / macOS / 网页版），支持 Draw、Blocks、JavaScript、Python | 官方支持，连接最稳定，能升级固件 | 代码跑在 App 里，不能接入我们自己的程序 | **用来检查硬件、升级固件、校准** |
| B. Python 库 `spherov2` | `spherov2` + `bleak`（BLE） | 开源、跨平台，有和 Sphero Edu 几乎一样的高层 API（`SpheroEduAPI`），明确支持 BOLT | 非官方，偶尔有蓝牙兼容问题 | **本项目主路线** |
| C. 其他 Python 库 | `pysphero`（基于 bluepy，仅 Linux） | 专门在 BOLT 上测过 | 只能在 Linux 上用，维护不活跃 | 备选 |
| D. 自己写 BLE 协议 | `bleak` 直接收发数据包 | 完全可控 | 工作量大，要自己实现 Sphero V2 协议 | 后期需要时再考虑 |

**结论：先用路线 A 确认硬件正常，然后用路线 B（`spherov2`）取得程序控制权。**

> 注意：如果你的球是 **BOLT+**（带 LCD 屏幕的新款），原版 `spherov2` 可能不完全兼容。可以改用 UNSW 的分支 `sphero_unsw`（`pip install sphero_unsw`），它在 `spherov2` 基础上增加了 BOLT+ 支持。

---

## 2. 准备工作（硬件）

1. **充电**：把 BOLT 放在充电座上充满电（指示灯常亮表示充满）。
2. **唤醒**：从充电座上拿下来，或者放回充电座再拿下来，BOLT 会亮灯并进入可连接状态。
3. **用 Sphero Edu App 检查一次**：
   - 安装 Sphero Edu，连接 BOLT，按提示**升级固件**（第三方库在最新固件上最稳定）。
   - 在 Drive 模式下开一圈，确认电机、LED 矩阵都正常。
   - 记下 App 里显示的机器人名字，一般是 `SB-XXXX` 这种格式（`XXXX` 是 4 位编码）。后面要用它来指定连接哪颗球。
4. **断开 App**：BLE 同一时刻只能连一个主机。**一定要在 App 里断开，或者直接关掉 App**，否则 Python 扫不到或连不上。

---

## 3. 准备工作（电脑）

| 项目 | 要求 |
| --- | --- |
| Python | 3.10 – 3.12（`sphero_unsw` 标注支持到 3.12，用这个范围最保险） |
| 蓝牙 | 电脑要有支持 BLE（蓝牙 4.0+）的适配器，并且已打开 |
| 系统 | Windows 10/11、macOS、Linux（BlueZ）都可以；注意事项见第 7 节 |

```bash
# 建议用独立的虚拟环境
python -m venv .venv
# Windows:      .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate

pip install spherov2 bleak
# 如果是 BOLT+：pip install sphero_unsw bleak
```

macOS 首次运行时，系统会弹窗请求蓝牙权限。要给运行脚本的终端或 IDE（Terminal、iTerm、VS Code 等）授权。

## 4. 分步验证计划

每一步都对应一个小脚本，计划放在仓库的 `scripts/` 目录里。前一步通过了再做下一步。

### Step 1：扫描，找到 BOLT

```python
# scripts/01_scan.py
from spherov2 import scanner

toys = scanner.find_toys(timeout=10)
for t in toys:
    print(type(t).__name__, t.name, t.address)
```

✅ 通过标准：输出里有 `BOLT  SB-XXXX  <地址>`。

### Step 2：连接并点亮 LED（Hello World）

```python
# scripts/02_hello_led.py
import time
from spherov2 import scanner
from spherov2.sphero_edu import SpheroEduAPI
from spherov2.types import Color

toy = scanner.find_toy(toy_name="SB-XXXX")   # 换成你的球的名字
with SpheroEduAPI(toy) as api:
    api.set_main_led(Color(r=0, g=0, b=255))  # 整个矩阵变蓝
    time.sleep(2)
    api.set_front_led(Color(r=0, g=255, b=0))
    api.set_back_led(Color(r=255, g=0, b=0))
    time.sleep(2)
```

✅ 通过标准：BOLT 先变蓝，然后前灯变绿、后灯变红。

### Step 3：LED 矩阵显示文字

```python
# scripts/03_matrix.py
import time
from spherov2 import scanner
from spherov2.sphero_edu import SpheroEduAPI
from spherov2.types import Color

toy = scanner.find_toy(toy_name="SB-XXXX")
with SpheroEduAPI(toy) as api:
    api.scroll_matrix_text("HI", Color(255, 255, 255), fps=10, wait=True)
```

✅ 通过标准：矩阵上滚动显示 "HI"。

### Step 4：运动控制

> 先把球放在**地上、空旷的地方**，远离桌边和楼梯。

```python
# scripts/04_move.py
import time
from spherov2 import scanner
from spherov2.sphero_edu import SpheroEduAPI

toy = scanner.find_toy(toy_name="SB-XXXX")
with SpheroEduAPI(toy) as api:
    api.spin(360, 1)              # 原地转一圈，用时 1 秒
    api.roll(0, 60, 2)            # 朝 0° 方向，速度 60，滚 2 秒
    api.roll(180, 60, 2)          # 掉头滚回来
    api.stop_roll()
```

**关于“前方”（0°）**：BOLT 的 0° 方向就是连接那一刻后灯（蓝色小灯）对着你时的正前方。精确控制前要先**对准方向**：
- 用 App 的 Aim 功能对准；或者
- 在代码开头调用 `api.set_heading(...)` / `api.reset_aim()` 修正；
- BOLT 有罗盘，可以用 `api.calibrate_compass()` 做罗盘校准。

✅ 通过标准：原地转一圈，往前滚，再回到大致原来的位置。

### Step 5：读取传感器

```python
# scripts/05_sensors.py
import time
from spherov2 import scanner
from spherov2.sphero_edu import SpheroEduAPI

toy = scanner.find_toy(toy_name="SB-XXXX")
with SpheroEduAPI(toy) as api:
    for _ in range(20):
        print("姿态:", api.get_orientation(),
              "加速度:", api.get_acceleration(),
              "光照:", api.get_luminosity(),
              "罗盘:", api.get_compass_direction())
        time.sleep(0.5)
```

✅ 通过标准：用手转动、晃动球，读数会跟着变化；用手遮住球，光照值会下降。

### Step 6：键盘遥控（取得“实时控制”）

把运动控制和键盘输入接起来（比如用 `pynput` 或 `keyboard` 库）：方向键控制 heading 和 speed，空格键停止。
✅ 通过标准：可以在房间里用键盘把 BOLT 开一圈。**到这一步，就算真正取得了控制权。**

## 6. 安全注意事项

- 第一次跑运动脚本时，用低速（≤ 60，最大 255），并在地面上运行。
- 每个脚本都用 `with SpheroEduAPI(toy) as api:`。这样脚本出错或退出时，会自动停车并断开连接。
- 运动脚本旁边留一个能马上停下的办法：Ctrl+C 中断，或者直接把球拿起来。
- 电量低时，蓝牙连接容易不稳定，先充电再测试。

## 7. 常见问题排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 扫描不到 BOLT | 球在休眠 / 还连着 App / 电脑蓝牙没开 | 放回充电座再拿起来唤醒；关掉 Sphero Edu；确认蓝牙已开 |
| 能扫到但连接超时 | 距离太远 / 干扰 / 固件太旧 | 靠近一点；用 App 升级固件；重启电脑蓝牙 |
| macOS 没有反应或报权限错误 | 终端没有蓝牙权限 | 系统设置 → 隐私与安全性 → 蓝牙，给终端或 IDE 授权 |
| macOS 下多线程相关报错 | 早期版本的 `BleakAdapter` 在 macOS 上有多线程问题 | 升级到最新版 `spherov2`；还不行就用库自带的 TCP 中继：先运行 `python -m spherov2.adapter.tcp_server`，代码里改用 `get_tcp_adapter('localhost')` |
| Linux 下连上了但收不到传感器数据 | BlueZ 的 D-Bus 有时不把通知包转发给 bleak（已知问题） | 升级 BlueZ 和 bleak；或者先用 Windows/macOS 开发 |
| BOLT+ 的部分功能报错 | 原版库还没适配 BOLT+ | 改用 `sphero_unsw` |
