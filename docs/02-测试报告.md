## 处理过的问题

### Python 3.15 与 spherov2 不兼容

最初使用 Python 3.15.2 时，LED 点阵的逐像素命令被 `spherov2` 错误判断为不支持。原因是 Python 3.15 修改了 `functools.partialmethod` 的内部元数据名称，而 `spherov2 0.12.1` 仍按旧名称检查。

处理方式：按照项目文档改用 Python 3.12.16，并重新建立虚拟环境。切换后矩阵接口能够正常工作。

### 碰撞通知解析警告

键盘遥控期间，`spherov2` 的后台线程偶尔出现碰撞通知数据包长度不匹配的异常：

```text
struct.error: unpack requires a buffer of 18 bytes
```

该异常未影响运动控制、急停、退出或蓝牙断开。目前可视为第三方库的非阻塞兼容问题，后续如需使用碰撞检测功能，应单独修复或升级相关解析逻辑。

### pynput 权限与退出日志

macOS 下 `pynput` 仍可能打印输入监控权限提示，但实际方向键、空格和 `Esc` 均能正常接收。按 `Esc` 停止监听器时还会输出 `StopException` 堆栈；程序随后正常执行停车、熄灯和断开连接，因此目前属于非阻塞日志噪声。
